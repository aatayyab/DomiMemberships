Membership applications, member directory, member portal, profile photos, and moderated member content. One dashboard page to manage everything.

== Description ==

WP Memberships turns your WordPress site into a members-only hub.

* Visitors apply online, or you add members yourself.
* Approve or reject applicants, change membership levels, suspend and reinstate members.
* Members get a private portal with a profile photo, personal details, and a Markdown editor.
* Members' approved posts become regular blog posts.
* A searchable member directory with photo cards and member profiles.
* Menus hide Join and Login for logged-in users.
* No emails are sent. No third-party services are required.

== Installation ==

1. Download the latest ZIP from the plugin's GitHub Releases page.
2. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
3. Choose the ZIP file and click Install Now, then Activate.
4. The Join, Member Directory, and Member Portal pages are created for you.
5. Open Memberships in the left menu to manage everything.

== Frequently Asked Questions ==

= Does it send emails? =
No. Share login details with new members yourself.

= Can members edit their posts after approval? =
No. They delete the post and submit a new one for approval.

= Do I need Imagick? =
No. The GD library is enough for profile photos.
